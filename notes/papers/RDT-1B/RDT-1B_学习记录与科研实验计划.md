## 1. 论文基本信息

- **标题**：RDT-1B: A Diffusion Foundation Model for Bimanual Manipulation
- **中文**：RDT-1B：面向双臂操作的扩散基础模型
- **会议**：ICLR 2025
- **作者**：Songming Liu、Lingxuan Wu 等，清华大学相关研究团队
- **论文**：https://arxiv.org/abs/2410.07864
- **项目**：https://rdt-robotics.github.io/rdt-robotics/
- **代码**：https://github.com/thu-ml/RoboticsDiffusionTransformer
- **学习材料**：本次对话上传的 `rtd-1b.pdf`（28 页）
- **相关知识**：RT-1、Octo、Diffusion Policy、DiT、VLA、模仿学习、双臂操作、跨机器人预训练

### 1.1 一句话总结

RDT-1B 将条件扩散动作生成、针对机器人物理数据改造的 Transformer、物理可解释的统一动作空间及大规模多机器人预训练相结合，以提升语言条件下的双臂操作与泛化能力。

### 1.2 研究动机

1. **双臂动作多模态**：同样的物体和指令，可能存在左手、右手或双手协作等多个可行轨迹；确定性回归在 MSE 下可能拟合出不可行的平均动作。
2. **双臂数据稀缺**：机器人硬件和遥操作采集成本高，单一双臂平台难以积累基础模型规模的数据。
3. **机器人数据异构**：不同平台在关节数、夹爪、末端执行器和底盘等物理字段及控制形式上存在差异。
4. **多模态数值训练困难**：机器人物理量存在非线性、高频变化与数值范围不稳定的问题；视觉与语言特征存在数量不均衡问题。

### 1.3 主要贡献及“是否首创”判断

| 内容 | 核心作用 | 理解时应注意 |
|---|---|---|
| 条件扩散动作生成 | 表达连续、多模态动作分布 | 扩散与 Action Chunk 均非 RDT 首创 |
| 改造 DiT（QKNorm、RMSNorm、MLP Decoder） | 增强数值稳定性和非线性动作预测 | 归一化技术本身并非该论文首创 |
| Alternating Condition Injection（ACI） | 交替注入图像和语言条件 | 论文的具体融合设计贡献 |
| Physically Interpretable Unified Action Space | 将不同机器人动作按物理语义映射到统一字段 | RDT 的核心方法贡献之一 |
| 多机器人预训练 + ALOHA 微调 | 利用广泛示范知识提升目标平台能力 | 系统性贡献不等于所有模块均由作者发明 |

**定位**：这是以离线示范数据进行**模仿学习**的机器人策略研究，不是使用 PPO 训练的强化学习项目。

### 2.1 第 1 讲：研究动机与任务定义

- 输入：语言指令 $\ell$、观测 $o_t$；观测包含图像历史、机器人本体状态、控制频率。
- 输出：用于机械臂控制的动作或动作块。
- 多模态：一个观察与指令可对应多个不同但都可行的动作模式。
- 直观例子：左右手都可以抓取方块；两个方案逐点取平均可能撞击障碍或失去可操作性。
- 跨机器人预训练主要用于改善**目标双臂机器人**泛化；不能据此声称模型可不加适配地直接控制任何机器人。

**交互记录**：提供了“多种动作模式与回归平均值”的示意及 3 道概念选择题；没有用户提交答案或得分的记录。

### 2.2 第 2 讲：扩散数学、Action Chunk

**加噪表达**（此处 $t$ 表示机器人时间、$k$ 表示扩散时间）：

$$
\tilde a_t^{k}=\sqrt{\bar\alpha_k}a_t+\sqrt{1-\bar\alpha_k}\epsilon,
\qquad \epsilon\sim\mathcal N(0,I)
$$

**RDT 的干净动作预测目标**：

$$
\mathcal L(\theta)=\operatorname{MSE}\Bigl(a_t,
 f_\theta(\ell,o_t,\tilde a_t^k,k)\Bigr)
$$

- **模型预测干净动作**，不是默认预测 $\epsilon$；这一点影响复现损失函数。
- 推理从高斯随机动作开始，根据当前视觉、语言和状态条件反复去噪。
- 训练采样噪声级别与推理求解器的步数不是一个概念。
- $a_{t:t+T_a}=(a_t,\dots,a_{t+T_a-1})$；Action Chunk 用一个动作序列减少不连贯性，并降低每个时间步都重新调用完整策略的需求。
- **预测长度** $H$ 与**实际执行长度** $E$ 可以不同；较短滚动执行可增加反馈，但带来额外重规划成本。

**交互记录**：提供了调节 $\bar\alpha_k$ 的加噪小实验、去噪步骤滑块和 3 道测验；无已提交答案记录。

### 2.3 第 3 讲：RDT 网络架构与多模态融合

| 路径 | 核心模块 | 功能 |
|---|---|---|
| 视觉输入 | 冻结 SigLIP，随后投影 | 将多视角图像转为视觉特征 |
| 语言输入 | 冻结 T5-XXL，随后投影 | 将指令转为语言特征 |
| 低维输入 | MLP + Fourier Features | 编码本体状态、带噪动作及其他物理数值 |
| 主干 | 修改后的 Diffusion Transformer | 对动作 Tokens 进行条件去噪 |
| 条件融合 | Cross-Attention + ACI | 在不同层交替引入图像/语言 Tokens |
| 输出 | 归一化 + 非线性 MLP Decoder | 预测干净动作块 |

- **QKNorm**：降低 Query/Key 数值尺度造成的注意力不稳定。
- **RMSNorm**：不进行均值中心化；论文基于时间序列特征给出替换 LayerNorm 的动机。
- **MLP Decoder**：在隐藏特征到物理动作之间增加非线性表达。
- **ACI**：避免视觉 Tokens 数量较多时语言信息被掩盖；不能简单说所有场景都必然优于其他融合策略。
- **随机独立 Masking**：训练时减少对特定视角或模态的过分依赖。

**交互记录**：SigLIP 流程、多视角图像、Fourier 频率滑块、DiT/ACI 对比示意、消融图和测验；没有答题提交记录。

### 2.4 第 4 讲：统一动作空间

- **统一物理表示为 128 维**，而不是所有机器人原生自由度都是 128。
- 单臂数据按论文定义映射到“右臂”字段。
- 物理维度缺失时使用 Padding；额外拼接 128 维有效性信息，得到编码前的 256 维向量，以区分“真实数值 0”和“填充值 0”。
- 不同机器人同名字段仍可能具有不同的关节轴、连杆结构和控制意义；统一动作空间不等于完全解决 Embodiment Gap。

**关键字段表**（Python 左闭右开切片）：

### 2.6 第 6 讲：批判性分析与 RT-1、Octo 比较

| 维度 | RT-1 | Octo | RDT-1B |
|---|---|---|---|
| 代表性动作方式 | 量化的离散动作 Tokens | Transformer + 扩散动作头 | DiT 作为条件去噪主干 |
| 核心问题 | 大规模视觉-语言控制 | 灵活、多机器人通用策略 | 大规模双臂连续精细动作 |
| 主要值得学习点 | Token 化与实时机器人控制 | 模块化策略、微调和扩散动作头 | 条件交替注入、统一动作空间、扩散 Transformer |

比较结论：**不能仅凭 RDT 比 Octo 某些实验表现更好，就证明“DiT 一定优于扩散头”**；数据、参数量、训练预算、输入条件均不同，需要受控消融。

**潜在局限/假设**（这里是研究分析，不是论文已经验证的失败原因）：

1. 统一物理动作字段不能完全消除机器人形态与运动学差异。
2. 多步扩散仍有推理延迟和算力成本。
3. 长 Action Chunk 的时序一致性与闭环反馈之间可能存在权衡。
4. 生成策略不天然给出一般性的关节/碰撞安全保证。
5. 个别测试样本量有限，跨种子稳定性值得进一步研究。

## 4. 实验项目：Mini-RDT 复现与扩展计划

### 4.1 科研问题和可证伪假设

- **H1**：在同一观测可对应两种有效路径时，条件扩散比 MSE 确定性回归更可能生成有效模式之一，而非不可行的平均路径。
- **H2**：当目标或障碍物在执行中发生变化时，短执行窗口/自适应重规划可能比执行完整预测动作块有更好的恢复能力，但可能增加延迟和控制不连续性。
- **H3（后续）**：比较 MDN 等概率模型后，进一步判断性能提升是否来自“多模态表达本身”，而非扩散采样的特殊优势。

H1 在教学数据上已有一次样例支持；**H2、H3 均尚未实验验证**。

### 4.4 实验指标与记录规范

- `success_rate = successful / total`：抵达目标且无碰撞。
- `collision_rate = collision / total`：沿路径线段判定是否碰撞障碍物。
- `goal_rate = reached / total`：终点是否在容差内，**不等价于成功率**。
- `mode_coverage`：上下两种合法轨迹模式的样本覆盖状况，同时统计无效轨迹比例。
- `smoothness`：可采用相邻动作差异均方和，但应与任务成功率共同报告。
- `inference_latency_ms`：在相同 CPU、线程数和推理配置下测量，记录均值及波动。
- `recovery_rate`：明确扰动幅度与介入时刻，用于闭环实验。
- 记录每个实验的 Python/PyTorch 版本、操作系统、seed、模型参数量、命令、源码提交号和测试样本数。
- **不拿不同训练目标的 Loss 值直接对比模型优劣**。
