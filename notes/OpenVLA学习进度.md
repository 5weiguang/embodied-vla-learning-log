| 整段执行滞后是推理太慢，或执行太慢 | 本例主要是连续执行旧计划、重新观察与决策间隔太长；不是必须由物理运动慢造成 |
| A/B 数据各一半较合适，但不知道最佳比例 | 等比例是候选采样方案，需考虑多样性、质量和固定评测；重复采样不会增加独立经验 |
| 同样处理样本数下，A 的 epoch 更多所以可能学到更多能力 | batch=100 时，1 万样本×10 轮和10 万样本×1 轮都更新 1000 次；不能只按 epoch 排能力 |
| 消费显卡能运行是否意味着相近成本训练 | 能正确解释推理与训练的区别；同时补充不能断言消费显卡完全不能微调 |
| 稀有动作被限制是对训练数据拟合不够 | 截断前处理已丢失原始幅度；即使准确预测处理后的标签，也不能恢复原值。讲解后表示理解 |
| 从 Prismatic 出发“再结合”三个基础组件 | 明确使用的 Prismatic 已包含这些组件；OpenVLA 在其上训练动作预测 |

## 仍需独立巩固

1. **表示误差与拟合不足：** 为什么增加训练轮次不能恢复被截断的极端动作。
2. **推理延迟与反馈间隔：** 为什么推理很快、连续执行旧动作仍会反应滞后。
3. **epoch 与实际训练量：** 不同数据规模下计算更新次数，再比较覆盖范围与重复程度。
4. **LoRA 显存：** 原权重、中间激活、梯度和优化器状态分别占用什么；11 月 1 日曾表示不能独立解释，尚未单独复述全部组成。
5. **实验结论边界：** 特定任务结果、模型版本脚注和控制条件；经验趋势不能推广为所有任务保证。

上述即时回答、纠错后理解与独立掌握分别记录，不把“表示理解”自动升级为全部会独立推导。
